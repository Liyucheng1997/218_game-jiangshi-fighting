# 真理斗僵尸 · ZOMBIE STRIKE

基于 **Three.js** 的中国僵尸题材第一/第三人称射击游戏。你是道长**林正英**，持枪与火符，
在义庄古街迎战由《子不语》《续子不语》尸变传说构成的僵尸谱系——从初变的紫僵，一路打到僵尸之王**犼**。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5208 。打包发布：`npm run build`。

## 游戏结构

- **主菜单**：出战 / 僵尸图鉴 / 道长修行
- **僵尸图鉴**：3D 灵堂，八口立棺一字排开，僵尸立于棺中。点击棺木或用 ←/→ 切换，查看每种僵尸的传说设定与战斗数值
- **七大关卡**（带剧情引入，难度递进，环境氛围随关卡变化）：
  1. 乱葬岗 · 尸动 —— 伏尸 / 紫僵
  2. 义庄 · 白雾 —— 白僵（怕火，火符 ×2 伤害）
  3. 荒村 · 尸气 —— 绿僵（快而力大）
  4. 竹林 · 妖变 —— 毛僵（**刀枪不入**：枪械伤害 ×0.45，用火符烧）
  5. 夜空 · 飞僵 —— 飞僵（一跃数丈，快逾奔马）
  6. 赤地 · 旱魃 —— 旱魃（精英：灼烧光环，近身持续掉血）
  7. 决战 · 犼 —— **BOSS 战**：3600 血、蓄力冲撞、BOSS 血条
- **道长修行**（击杀得分换取**阳气**，localStorage 持久化）：
  铜皮铁骨（生命上限）/ 轻功提纵（移速）/ 百步穿杨（枪伤）/ 敕令真火（火符强化）

## 操作

| 按键 | 功能 |
| --- | --- |
| W A S D / Shift / 空格 | 移动 / 疾跑 / 跳跃 |
| 鼠标左键 | 射击 |
| **鼠标右键 / Q** | **掷火符**（抛物线飞行，落地或贴怪爆出真火 AOE） |

## 技术要点

- Three.js（WebGL2）+ Vite，纯前端；进度存 localStorage
- **模型**：9 个 AI 生成（Tripo）角色 GLB（8 僵尸 + 林正英），经 gltf-transform 优化（WebP 纹理、~800KB/个）；
  按关卡懒加载；`SkeletonUtils.clone` 实例化
- **动画**：模型带骨架，加载时会修复 Tripo 稀疏/漏绑的手臂蒙皮权重，再由安全 joint 驱动
  双臂前举、三段式爪击和图鉴专属舞步；蹦跳、受击、倒地及林正英走路同样由程序动画完成。
- **图鉴舞蹈**：8 类僵尸各有独立节奏、摆臂、扭身与弹跳编排，选中者完整演出，邻棺低幅伴舞。
- **火符**：抛物线投掷物 + 近炸/落地引爆 + 火焰 AOE（对白僵/毛僵有克制倍率）+ 地面残焰光效
- **第三人称**：过肩相机，林正英模型程序化走路动画；准星射击逻辑两种视角通用
- **BOSS AI**：犼在中距离蓄力（前兆动作）后直线冲撞，冷却循环；旱魃灼烧光环持续伤害 + 灼烧滤镜
- 碰撞（高度感知圆柱 vs AABB）、打击感（震屏/击退/抛壳/枪口火光）、WebAudio 合成音效等继承自前版
